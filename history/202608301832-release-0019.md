# Release 0.0.19 / 发布 0.0.19

## 中文

- 发布 generation-gated 浏览器 WebSocket client state machine。
- 新增 `WsClient` 方法 API：`.connected?`、`.send`、`.close` 与
  `.reconnect`；`.send` 返回类型化 `WsSendOutcome`。
- 重连会忽略旧 generation 迟到的 `open/message/close/error` 回调，并通过
  生成 JS 上的 fake WebSocket smoke 守门。
- 要求 Calcit CLI 与 `@calcit/procs` 精确使用 0.13.66。

## English

- Release the generation-gated browser WebSocket client state machine.
- Add `WsClient` methods `.connected?`, `.send`, `.close`, and `.reconnect`,
  with a typed `WsSendOutcome` from `.send`.
- Ignore late `open/message/close/error` callbacks from stale generations and
  guard the behavior with a generated-JS fake WebSocket smoke.
- Require the exact Calcit CLI / `@calcit/procs` 0.13.66 pair.
