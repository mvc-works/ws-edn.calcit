# Upgrade to Calcit 0.13.77 / 升级到 Calcit 0.13.77

## 中文

- 将 Calcit 与精确 `@calcit/procs` 从 0.13.76 对齐到 0.13.77，并升级唯一的 Calcit 模块依赖 cumulo-util 到不可变发布 `0.0.17`。
- 将 `WsClientOps/.send` 与其实现的 payload 从裸 `Dynamic` 收窄为方法泛型，确保 ws-edn 作为依赖被 0.13.77 消费者加载时通过严格 trait 构造，同时保留任意 Cirru EDN payload 能力。
- 保持 ws-edn 模块与 npm 包版本 `0.0.24`、WebSocket 消息格式、generation guard、重连和 heartbeat timeout 行为不变。
- 修正 README 中的旧版本引用与示例语法，并明确区分需要 Node/WebSocket host 的片段和可由 Markdown runner 独立执行的数据示例。
- 将 CI Actions 固定到已核验的不可变 commit，并补充严格 Caps、精确 toolchain 与 server entry 动态方法门禁。

## English

- Align Calcit and exact `@calcit/procs` from 0.13.76 to 0.13.77, and upgrade the sole Calcit module dependency to the immutable cumulo-util `0.0.17` release.
- Replace the bare `Dynamic` payload in `WsClientOps/.send` and its implementation with a method generic, allowing strict trait construction when 0.13.77 consumers load ws-edn while preserving arbitrary Cirru EDN payloads.
- Preserve ws-edn module and npm package version `0.0.24`, WebSocket message format, generation guard, reconnect behavior, and heartbeat timeout behavior.
- Correct stale README versions and example syntax, and distinguish Node/WebSocket-host snippets from data examples that the Markdown runner can execute independently.
- Pin CI Actions to reviewed immutable commits and add strict Caps, exact toolchain, and server-entry dynamic-method gates.
