# Release 0.0.18 / 发布 0.0.18

## 中文

- 发布 ws-edn.calcit 0.0.18，要求 Calcit CLI 与 `@calcit/procs` 0.13.64。
- 精确固定 npm runtime 版本，避免 CLI 与生成 JS 的 proc 语义漂移。
- 保持 page/server WebSocket API、strict macro contracts 与 `Unit` send 语义不变。

## English

- Release ws-edn.calcit 0.0.18 with Calcit CLI and `@calcit/procs` 0.13.64 required.
- Pin the npm runtime exactly to prevent proc semantic drift between the CLI and generated JS.
- Keep the page/server WebSocket API, strict macro contracts, and `Unit` send semantics unchanged.
