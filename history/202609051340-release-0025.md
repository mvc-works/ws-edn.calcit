# Release 0.0.25 / 发布 0.0.25

## 中文

- 发布 Calcit 与 `@calcit/procs` 0.13.77 兼容版本，并使用已发布的 Cumulo util 0.0.17。
- 保持既有 WebSocket 消息、重连、心跳超时、generation 隔离与客户端/服务端生命周期行为不变。

## English

- Release compatibility with Calcit and `@calcit/procs` 0.13.77 using the published Cumulo util 0.0.17.
- Preserve the existing WebSocket messages, reconnect behavior, heartbeat timeout, generation isolation, and client/server lifecycle semantics.
